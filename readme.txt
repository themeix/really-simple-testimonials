== Description ==

== Installation ==

= Installation from within WordPress =

1.  Visit **Plugins > Add New**.
2.  Search for **Really Simple Testimonials**.
3.  Install and activate the plugin.

= Manual installation =

1.  Upload the entire `really-simple-testimonials` folder to the `/wp-content/plugins/` directory.
2.  Visit **Plugins**.
3.  Activate the plugin.

== Getting Started ==

1.  **Create Testimonials**: Go to **Testimonials > Add New** to create customer testimonials with author info, ratings, and feedback.
2.  **Generate Shortcode**: Visit **Testimonials > Generate Shortcode** to configure your testimonial display settings.
3.  **Customize Design**: Choose from 5 beautiful themes, customize colors, fonts, and spacing.
4.  **Add to Pages**: Copy the shortcode and paste it into any page, post, or widget.
5.  **Enable Frontend Submission**: Configure frontend form options to allow customers to submit testimonials.
